Execution order:

1. meeting intake creates prep artifacts early
2. morning digest reads active plan plus those artifacts
3. pre-meeting reminder points back to the prep artifact
4. post-meeting capture drafts promised follow-up and updates loops
5. evening reset records what moved and sets tomorrow's first move
